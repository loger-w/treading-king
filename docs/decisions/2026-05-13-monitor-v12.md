## 已知簡化（trade-off）

1. **TradeTape 不顯示單量** — `fubon_ws.py:217` broadcast tick 目前 payload 只含 `symbol` + `price`。
   - **未來：** backend broadcast 加 `size` 後，`useTradeTape` 補上 `vol` 欄位。
2. **內外盤用相鄰價判定** — 沒有對委買賣比對。
   - **未來：** 同上，broadcast 帶 `bid`/`ask` 後做正確判定。
3. **五檔走 REST poll 2s** — 不是真即時。
   - **未來：** 升級為 WS `books` channel；要先 probe trades+books 共連線容量。
4. **TradeTape 重連時失去歷史** — 切 symbol 即清空。
   - 不影響功能，但 reload 後等第一筆 tick 才有資料。
